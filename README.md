# CVS System Frontend

Base do frontend do MVP descrito no PRD em [`docs/PRD.md`](./docs/PRD.md).

## Stack inicial

- Nuxt 4
- PrimeVue 4
- Chart.js 4
- Tema global com fonte `Manrope`

## Configuração

Instale as dependências:

```bash
npm install
```

Crie o arquivo `.env` a partir de `.env.example` e ajuste a URL da API do backend quando necessário.

## Desenvolvimento

```bash
npm run dev
```

## Build de produção

```bash
npm run build
```
